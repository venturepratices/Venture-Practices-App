Add the Pipedrive key first

The app needs a Pipedrive API token to read your Pipedrive account. It is kept in Vercel and never shown here.

  1. In Vercel, open the project, then Settings, then Environment Variables.
  2. Add PIPEDRIVE_API_TOKEN for Production, with the token from Pipedrive (Personal preferences, API).
  3. Redeploy the app, then come back to this page.
